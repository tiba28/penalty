# pena — 仲間内ペナルティ管理アプリ

仲間内（サークル・チーム・友人グループ）で、遅刻や欠席などのルール違反に点数（ペナルティ）を付け、
ランキング化して楽しむ Web アプリ。「みんなの合意で成り立つ、民主的なペナルティ帳」がコンセプト。

## 特徴

- ルールは **全員の同意** で成立（例: 遅刻=1点）
- 加点は **本人以外の全員が48時間以内に承認** で確定（1人でも却下 or 未回答なら却下）
- 点数を貯めて **ランキング**、一定点数で **罰**（内容はユーザーが自由に設定）
- お金・決済は扱わない（罰の中身は「罰ゲーム」でも「おごり」でも自由）
